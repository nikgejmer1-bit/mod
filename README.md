# Wheat Sweep — Fabric 1.21.11

Небольшой мод для Minecraft Java Edition 1.21.11 (Fabric). Добавляет цепную уборку и цепную посадку пшеницы.

## Сбор урожая

1. Возьми любую мотыгу в основную руку.
2. Зажми **Shift**.
3. Сломай **созревшую пшеницу**.
4. Каждая зрелая пшеница проверяет квадрат **3×3** вокруг себя. Цепочка продолжится по всей связанной области зрелой пшеницы на той же высоте, в том числе по диагонали.

Собранные растения остаются посаженными и сбрасываются до первой стадии роста. Дропы рассчитываются обычной таблицей лута Minecraft. Незрелая пшеница не затрагивается. Каждое дополнительное собранное растение расходует прочность мотыги; в творческом режиме прочность не тратится.

## Массовая посадка

1. Возьми **семена пшеницы** в любую руку.
2. Зажми **Shift**.
3. Нажми ПКМ по свободной грядке.
4. Мод посадит пшеницу на соседних свободных грядках, продолжая цепочку через каждый успешно засаженный блок.

Каждая посаженная грядка проверяет квадрат **3×3** вокруг себя. Посадка идёт только на увлажнённые грядки с пустым местом сверху, на той же высоте и в пределах загруженных чанков. Сухие грядки пропускаются. На каждую посаженную пшеницу тратится одно семя; в творческом режиме семена не расходуются. За один клик обрабатывается не более 1024 растений, чтобы не создавать чрезмерную нагрузку на сервер.

Без Shift всё остаётся по-ванильному: обычная посадка и обычный сбор урожая.

## Требования

- Minecraft Java Edition **1.21.11**
- **Fabric Loader 0.18.1** или новее
- **Fabric API 0.141.6+1.21.11**
- **Java 21** для сборки

## Сборка JAR

В корневой папке проекта выполни `build.bat` на Windows или `./build.sh` на Linux/macOS. Скрипт скачает Gradle 9.2.1 в пользовательскую папку кэша и запустит сборку. Для первой сборки нужен интернет.

Готовый файл появится в `build/libs/` и будет называться примерно так:

```text
wheat-sweep-1.2.0.jar
```

Помести JAR в папку `mods`. Fabric API тоже должен быть установлен.

## Мультиплеер

На выделенном сервере установи мод на сервер. Игрокам для работы мода нужен Fabric API, а клиентам — Fabric Loader.
